# 展示会当日の操作

## スタッフが注文を受ける

1. スタッフ画面にログインし、画面下部の「＋ 新しい注文」を押します。
2. 品番を検索して商品を追加します。検索結果の「新卸価格」はマスターQ列の値です。お客様への注文金額は、カートと確定前の明細でウォン単価・合計を確認します。
3. 「注文内容へ進む」を押し、名刺を撮影するか、店舗名・電話番号を入力します。名刺はプレビューで確認し、「名刺を追加」で合計5枚まで登録できます。備考も入力できます。
4. 商品と数量、金額、名刺を確認して「注文を確定」を押します。通信に失敗したら同じ画面で再試行します。
5. 受付番号とQRが表示されたら、お客様の端末で読み取ってもらいます。韓国語の控え画像が開くので、画像を長押しして保存します。複数ページの控えは各画像を保存します。「新しい注文」で次の注文を開始できます。

## 控えと代理店向けPDF

- 注文履歴で受付番号を検索し、注文詳細を開きます。修正した場合は保存してから、控えQRを再表示するか注文書を印刷します。
- 個別注文は注文詳細の印刷ボタン、全件はメニューの「全注文をPDF出力」を使います。印刷ダイアログで用紙をA4、保存先を「PDFに保存」にします。
- 全件PDFの先頭で件数・受付番号・合計を確認します。各注文の明細と名刺ページを確認し、PDFを韓国代理店のKY-S Corporation.へ手動で送付します。画像取得に失敗した場合は警告に表示されます。

## 開場前の確認

スタッフ画面でテスト注文を作り、別の端末でQRを読み取って韓国語の控えを確認します。テスト注文は注文詳細から削除履歴へ移します。旧注文の確認・送付記録が必要な場合は、メニューの「旧注文・送付履歴の管理」を開きます。

## 注文を削除・復元する

削除は必ず注文詳細の「削除履歴へ移す」を使用します。理由を選び、実行します。データは消えません。

復元は右上の「削除履歴」から「元に戻す」を押します。削除前が送付済みだった注文は、送信履歴を保持したまま送付済みへ戻ります。通常スタッフは完全削除を行いません。

## 代理店へまとめて送る

1. 上の日付フィルターで対象日を1日選ぶ。
2. 「確定注文をまとめて送る」を押す。
3. 対象注文・件数・数量・金額・再送件数を確認する。
4. 「注文PDFを作成・印刷」を押し、印刷画面で「PDFに保存」を選ぶ。
5. 「メール本文を開く」を押し、保存したPDFをメールへ添付して送信する。
6. 「PDFを保存しました」「PDFをメールへ添付して送信しました」の両方にチェックする。
7. 「代理店送付済みにする」を押す。

メール送信前に「送付済み」にしないでください。PDF作成後に作業を中止する場合はダイアログの「閉じる」を押し、バッチ中止を確認します。

## 送付済み注文を修正する

送付済み注文を編集すると警告が出ます。修正理由を入力して保存すると「修正版・再送待ち」へ移ります。次回の一括送付PDFには `REVISED ORDER / 修正版 / Revision N` が表示されます。

## 通信・ログインのトラブル

- 「10秒ごとの自動更新」：Realtimeが切れていますが運用可能です。必要なら「更新」を押します。
- 「DB更新が必要です」：新しいSupabaseマイグレーションが未適用です。管理者へ連絡します。
- ログイン期限切れ：再ログインします。
- 注文送信失敗：入力を消さず、接続確認後に再送します。同じ受付が重複しない設計です。
- 他スタッフとの競合：最新内容を読み込み直し、もう一度確認します。
