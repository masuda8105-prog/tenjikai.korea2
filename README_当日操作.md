# 展示会当日の操作

## 開場前（約10分）

1. お客様用ページとスタッフ用ページをChrome/Safariで開きます。
2. スタッフがログインでき、右上に自分の名前が表示されることを確認します。
3. お客様画面でテスト注文を1件送信し、スタッフ画面へ10秒以内に表示されることを確認します。
4. テスト注文を「対応開始 → 注文を確定する → 削除履歴へ移す」まで操作し、削除履歴から復元できることを確認します。
5. 通知音を使う端末だけ「通知音ON」にします。

## お客様の注文受付

お客様画面は次の3操作だけです。

1. 品番・商品名を検索し、「追加」を押す。
2. 下部のカートで商品と数量を確認する。
3. 「注文手続きへ」を押し、会社名・氏名・電話番号を入力して「注文を送信」を押す。

名刺写真は任意です。送信中は画面を閉じず、受付番号が表示されるまで待ちます。通信失敗時も入力は残るため、ネット接続を確認して同じボタンを再度押します。受付番号が一度表示された注文は、完了画面を閉じても保存済みです。

## スタッフの注文確認

1. 「確認待ち」の注文を開く。
2. 「対応開始」を押す。
3. 会社名・氏名・電話番号、名刺、品番、数量、金額を確認する。
4. 必要なら数量やお客様情報を修正し、「変更を保存」を押す。商品追加は品番を入力して行う。
5. 「注文を確定する」を押す。注文は「送信待ち」へ移る。

別スタッフが先に更新した場合は競合メッセージが出ます。入力内容を確認し直し、最新状態から操作してください。

## 注文を削除・復元する

削除は必ず注文詳細の「削除履歴へ移す」を使用します。理由を選び、実行します。データは消えません。

復元は右上の「削除履歴」から「元に戻す」を押します。削除前が送付済みだった注文は、送信履歴を保持したまま送付済みへ戻ります。通常スタッフは完全削除を行いません。

## 代理店へまとめて送る

1. 上の日付フィルターで対象日を1日選ぶ。
2. 「確定注文をまとめて送る」を押す。
3. 対象注文・件数・数量・金額・再送件数を確認する。
4. 「注文PDFを作成・印刷」を押し、印刷画面で「PDFに保存」を選ぶ。
5. 「メール本文を開く」を押し、保存したPDFをメールへ添付して送信する。
6. 「PDFを保存しました」「PDFをメールへ添付して送信しました」の両方にチェックする。
7. 「代理店送付済みにする」を押す。

メール送信前に「送付済み」にしないでください。PDF作成後に作業を中止する場合はダイアログの「閉じる」を押し、バッチ中止を確認します。

## 送付済み注文を修正する

送付済み注文を編集すると警告が出ます。修正理由を入力して保存すると「修正版・再送待ち」へ移ります。次回の一括送付PDFには `REVISED ORDER / 修正版 / Revision N` が表示されます。

## 通信・ログインのトラブル

- 「10秒ごとの自動更新」：Realtimeが切れていますが運用可能です。必要なら「更新」を押します。
- 「DB更新が必要です」：新しいSupabaseマイグレーションが未適用です。管理者へ連絡します。
- ログイン期限切れ：再ログインします。
- 注文送信失敗：入力を消さず、接続確認後に再送します。同じ受付が重複しない設計です。
- 他スタッフとの競合：最新内容を読み込み直し、もう一度確認します。
