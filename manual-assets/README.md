# 展示会マニュアル生成素材

`screens/` は、配布用マニュアルに掲載する現行画面の日本語・韓国語サンプル画像です。
`scenes/` は、会場での利用イメージを伝える紹介資料用の人物・展示会シーンです。

- お客様画面は公開中の本番ページを使い、サンプル商品・サンプル顧客情報で撮影しています。
- 受付番号画面は、Supabaseへ注文を登録しないローカル表示用サンプルです。
- スタッフのログイン後画面は、本番注文データや認証情報を資料へ含めないため、現行UIの構成・文言に合わせたサンプル注文を生成スクリプト内で描画しています。
- 人物・展示会シーンは資料用に生成したイメージで、実在のお客様・スタッフではありません。

マニュアルを再生成する場合：

```powershell
python tools/generate_exhibition_manuals.py
```

生成先：

- `output/pdf/`：日本語・韓国語のお客様ガイド、スタッフ簡易マニュアル、全体紹介資料のA4印刷用PDF
- `output/manual/`：配布・共有用PNG
